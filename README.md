## Código y publicación

El paquete `BEWAY-Fichas-GitHub-Pages.zip` contiene los HTML, estilos, scripts, imágenes, fuentes y recursos de las diez fichas. El workflow `.github/workflows/pages.yml` extrae su carpeta `public/` y la publica en GitHub Pages. Para actualizar una ficha, modifica el contenido del paquete y reemplázalo en `main`.

Los enlaces de «Explora empresas» de las fichas llevan al directorio de este repositorio. No se necesita acceso a ChatGPT para visitarlas.
